# دار الطيبات - موقع PHP

## ضع الملفات الأصلية في assets/
brand.jpg  |  product-1.webp ... product-12.webp  |  catalog.pdf

## التشغيل محليًا
php -S localhost:8000   (من داخل مجلد المشروع، يلزم PHP 7.4+)

## النشر
ارفع كل المجلد إلى public_html على استضافة تدعم PHP (cPanel وغيرها). Netlify لا يشغّل PHP.
